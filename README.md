# CoSpace — REST API для бронирования рабочих мест в коворкинге

Бэкенд-приложение на Spring Boot для управления рабочим пространством. Позволяет регистрировать сотрудников, добавлять доступные рабочие места (spaces) и бронировать их с автоматической валидацией пересечений по времени.

## Технологический стек
* **Java 21**
* **Spring Boot 4.x** (Spring Data JPA, Spring Web)
* **PostgreSQL**
* **Lombok**
* **Hibernate / Развёртывание схемы DDL**

## Основной функционал
1. **Управление пользователями**: Регистрация сотрудников компании.
2. **Управление пространствами**: Добавление рабочих мест в систему.
3. **Умное бронирование**:
    * Создание брони с автоматической проверкой доступности места на указанный период.
    * Поиск всех бронирований конкретного пользователя.
    * Перенос бронирования (обновление данных) с валидацией таймслотов.
    * Отмена (удаление) бронирования.
4. **Централизованная обработка ошибок**: Возврат кастомных JSON-ответов при бизнес-ошибках (например, если место занято).

## Структура Базы Данных (Связи)
* `User` - `Booking` (`@OneToMany`)
* `Space` - `Booking` (`@OneToMany`)

## API Эндпоинты

### Пользователи (Users)
* `POST /api/users` — Создать нового пользователя.

### Рабочие места (Spaces)
* `POST /api/spaces` — Создать рабочее место.
* `GET /api/spaces` — Получить список всех мест.

### Бронирования (Bookings)
* `POST /api/bookings` — Забронировать место.
* `GET /api/bookings/user/{userId}` — Посмотреть брони сотрудника.
* `PUT /api/bookings/{bookingId}` — Изменить параметры/время брони.
* `DELETE /api/bookings/{bookingId}` — Отменить бронь.

## Тестирование (Postman)
Все эндпоинты приложения были протестированы с помощью **Postman**
